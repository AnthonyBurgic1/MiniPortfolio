About the Project

This project is a personal mini portfolio website created with React and Next.js. The purpose of the application is to present my professional profile, technical skills, projects, and contact information in a modern and visually appealing format.

The website was created for COMP2112 and demonstrates my understanding of Next.js routing, React components, TypeScript, responsive CSS, and client-side form handling.

Pages

The portfolio contains five main pages:

Home - Landing page with a welcome message and mission statement.

About Me - Personal biography, image, interests, and professional mission.

Projects - Three featured projects with descriptions, technologies, and images.

Skills - Technical skills and technologies I have experience with.

Contact - Contact form that displays submitted information and redirects the visitor to the About Me page.
